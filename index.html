Upstream Price Pressures and Consumer Inflation: Testing Supply Chain Price Transmission in the U.S.

Python · NumPy · SciPy

Tested whether upstream price pressures — at the producer and import stage — systematically lead U.S. consumer prices, linking the bullwhip effect to macro-empirical inflation evidence.

Analyzed CPI, PPI (Final Demand), and Import Price Index data (BLS, Jan 2015–Jul 2026) using cross-correlation and pairwise Granger-causality F-tests across multiple lag structures.

p = 0.021 import prices → CPI, 1-month lag  ·  one-way, CPI never Granger-causes import prices

Finding — import prices Granger-cause CPI without reverse causality, consistent with import prices acting as a genuinely exogenous upstream shock; producer and consumer prices show strong bidirectional causality.

Amazon Sales & Customer Sentiment Analysis

Python · Pandas · Scikit-learn · TextBlob · NLTK (VADER)

Modeled discount depth as a function of price, rating, and category across 1,465 Amazon products, scoring review sentiment with TextBlob and VADER, comparing linear regression against Random Forest and tuned Gradient Boosting.

R² 0.16 → 0.32 linear baseline vs. tuned ensemble  ·  price + rating: only significant linear predictors

Finding — discounting behavior is meaningfully non-linear, though most variance stays unexplained by product attributes alone — likely driven by seller strategy, inventory, and seasonality.

Predicting Global Life Expectancy Using Machine Learning

Python · Scikit-learn · Matplotlib/Seaborn

Modeled life expectancy across 193 countries (WHO, 2000–2015) from socioeconomic and health indicators, comparing Linear Regression, Decision Tree, and Random Forest on an 80/20 split.

R² = 0.967 Random Forest, held-out test  ·  77% of importance from HIV/AIDS + income composition

Finding — Random Forest (MAE 1.05 yrs) outperformed Decision Tree (R² 0.916) and Linear Regression (R² 0.820); HIV/AIDS mortality and income composition dominate predictive weight.
